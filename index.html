Project Overview

The Cell Tower Health & Dropped Calls project is a data engineering solution designed to process and analyse cell tower call records.

The pipeline handles raw telecom call data, performs data-quality validation and cleansing, removes duplicate records, identifies rejected records and produces an analytical Gold-layer dataset at tower and hourly level.

The resulting dataset can be used to analyse dropped-call behaviour, tower performance, concurrent calls and utilisation.

06

Gold Layer Analysis

Drop Rate

Drop rate is calculated at tower and hour level using dropped calls divided by total calls.

Peak Concurrency

Concurrent calls are derived from call start and end events to determine peak concurrent activity.

Utilisation

Tower utilisation is derived from peak concurrency relative to available capacity.

Average Duration

The Gold layer also provides average call duration for each tower-hour combination.
